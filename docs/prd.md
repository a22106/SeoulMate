## 1. 문제 정의

### 1.1 배경

서울에 거주하는 외국인은 약 40만 명 이상이며, 유학생·근로자·결혼이민자 등 다양한 배경을 가진다. 이들은 일상에서 다음과 같은 반복적인 어려움에 직면한다.

- **언어 장벽으로 인한 문서 해독 불가**: 임대차 계약서, 공과금 고지서, 택배 안내문, 관공서 서류 등 한국어 문서를 이해할 수 없어 불이익을 당하거나 중요한 사항을 놓침
- **분리수거·생활 규칙의 복잡성**: 지역마다 다른 분리수거 규칙, 음식물 쓰레기 처리 방식 등이 한국어로만 안내되어 있어 위반 과태료 부과 위험
- **행정 절차의 불투명성**: 비자 연장, 외국인등록, 건강보험, 은행 계좌 개설 등 절차가 복잡하고 영어 안내가 부족
- **문화적 맥락 부재**: 한국 특유의 관습(보증금 제도, 전세/월세 차이, 경조사 문화 등)에 대한 이해 부족으로 실수 반복

### 1.2 기존 솔루션의 한계

- **정부 다국어 서비스(1345 등)**: 운영시간 제한, 대기시간 긴 편, 실시간 문서 해석 불가
- **온라인 커뮤니티(Reddit, Facebook 그룹)**: 정보의 정확성 보장 불가, 검색 어려움, 응답 지연
- **기존 번역 앱**: 단순 텍스트 번역만 제공, 맥락적 설명이나 행동 가이드 제공 불가

### 1.3 해결 목표

사진 한 장 또는 질문 한 줄로 한국 생활의 모든 문제를 즉시 해결할 수 있는 **AI 에이전트**를 만든다.

## 2. 제품 개요

### 2.1 한 줄 설명

> **"사진 찍고 물어보면 끝 — 서울 생활 완전 정복 AI 에이전트"**

### 2.2 핵심 가치 제안

SeoulMate는 Gemini의 멀티모달 능력을 활용하여 외국인이 서울에서 만나는 실생활 문제를 **사진 기반 즉시 해결**하는 AI 에이전트다. 단순 번역이 아닌, 한국 생활의 **맥락과 행동 가이드**를 함께 제공한다.

### 2.3 대상 사용자

| 페르소나                | 설명                        | 주요 Pain Point                  |
| ----------------------- | --------------------------- | -------------------------------- |
| 유학생 (20대)           | 한국어 초급, 첫 자취        | 계약서 이해, 분리수거, 행정 절차 |
| 외국인 근로자 (30대)    | 기본 한국어 가능, 장기 거주 | 세금, 보험, 법적 권리            |
| 디지털 노마드 (20-30대) | 한국어 불가, 단기 거주      | 일상 소통, 교통, 배달앱 사용     |
| 결혼이민자 (30-40대)    | 한국어 중급, 가정 운영      | 자녀 학교 서류, 관공서 업무      |

## 3. 핵심 기능 (MVP Scope)

### 3.1 📸 사진 기반 문서 해석 (Core Feature)

**사용 시나리오**: 사용자가 한국어 문서/안내문/표지판을 촬영하여 업로드

**기능 상세**:

- 촬영한 이미지를 Gemini Vision으로 분석
- 단순 번역이 아닌 **맥락적 해석** 제공 (예: "이 계약 조항은 보증금 반환 조건을 의미하며, 한국에서는 일반적으로...")
- 필요한 후속 행동을 단계별로 안내 (예: "이 고지서를 처리하려면 1) 편의점에서 2) 바코드를 스캔하여...")
- 위험/주의 사항이 있을 경우 경고 표시 (예: "이 계약서에 일반적이지 않은 조항이 포함되어 있습니다")

**지원 문서 유형**:

- 임대차 계약서 / 부동산 관련 문서
- 공과금 고지서 (전기, 가스, 수도)
- 택배 부재 안내문
- 관공서 서류 / 통지서
- 식당 메뉴판 / 안내 표지판
- 분리수거 안내문

### 3.2 💬 생활 상담 대화 (Core Feature)

**사용 시나리오**: 사용자가 자연어로 한국 생활 관련 질문

**기능 상세**:

- 한국 생활 전반에 대한 자연어 Q&A
- Gemini의 웹 검색(Grounding with Google Search)을 활용한 최신 정보 제공
- 사용자의 상황에 맞는 맞춤형 답변 (체류 자격, 거주 지역 등 고려)
- 관련 공공기관 링크 및 연락처 안내

**질문 예시**:

- "외국인등록증 연장은 어디서 해? 필요한 서류가 뭐야?"
- "이 동네 분리수거 요일이 언제야?"
- "전세 보증금 반환을 안 해주면 어떻게 해야 해?"
- "한국에서 은행 계좌 개설하려면?"

### 3.3 🎙️ 실시간 음성 대화 (Live API)

**사용 시나리오**: 손이 자유롭지 않거나 텍스트 입력이 어려운 상황에서 음성으로 즉시 질문

**기능 상세**:

- Gemini Live API를 통한 양방향 실시간 오디오 스트리밍
- 브라우저 마이크(PCM 16kHz) → WebSocket → FastAPI → Gemini Live API → 오디오 응답(PCM 24kHz) → 브라우저 스피커
- 짧고 대화체적인 응답 (1-3문장)으로 자연스러운 대화 경험
- 한국어 발음 교정 및 생활 한국어 학습 지원
- 모델: `gemini-2.5-flash-native-audio-preview` (폴백: `gemini-2.0-flash-live-001`)

**UI**: 플로팅 마이크 버튼 (화면 우하단), 탭으로 시작/종료

### 3.4 🚨 SOS 긴급 모드

**사용 시나리오**: 긴급 상황에서 한국어를 모르는 외국인이 즉시 도움 요청

**기능 상세**:

- API 호출 없이 오프라인에서도 동작하는 정적 데이터 기반
- 3개 카테고리: 경찰(112), 소방/구급(119), 병원(1339)
- 각 카테고리별 한국어 긴급 스크립트 + 로마자 발음 + 번역
- 원터치 전화 걸기 (`tel:` 링크)
- 스크립트 클립보드 복사
- 5개 언어 지원 (영어, 한국어, 중국어, 베트남어, 일본어)

**UI**: 헤더의 빨간 SOS 버튼 → 풀스크린 빨간 모달, 큰 글씨

### 3.5 🗂️ 카테고리별 퀵 가이드 (Supporting Feature)

**사용 시나리오**: 특정 주제에 대해 체계적인 정보가 필요할 때

**카테고리 구성**:

- 🏠 **주거**: 전세/월세 이해, 계약 체크리스트, 이사 절차
- 🗑️ **분리수거**: 구별 규칙, 종량제 봉투, 대형 폐기물
- 🏥 **의료/보험**: 건강보험 가입, 병원 이용, 약국 구매
- 📄 **비자/행정**: 체류자격별 절차, 출입국관리사무소 안내
- 🚇 **교통**: 교통카드, 지하철/버스 이용, 택시 팁
- 💰 **금융**: 은행 계좌, 송금, 세금 신고

### 4.3 Gemini API 활용 상세

#### 4.3.1 이미지 분석 프롬프트 설계

```
System Prompt:
당신은 서울에 거주하는 외국인을 돕는 전문 생활 어시스턴트입니다.
사용자가 보낸 이미지를 분석하고 다음 형식으로 응답하세요:

1. [문서 유형]: 이 문서/이미지가 무엇인지 식별
2. [핵심 내용]: 가장 중요한 정보를 사용자의 언어로 요약
3. [맥락 설명]: 한국 생활에서 이것이 의미하는 바를 설명
4. [행동 가이드]: 사용자가 취해야 할 구체적 단계
5. [주의 사항]: 놓치면 안 되는 기한, 과태료 등 경고

반드시 사용자의 언어({user_language})로 응답하되,
한국어 고유명사는 원문과 번역을 병기하세요. (예: 주민센터 (Community Service Center))
```

#### 4.3.2 Function Calling 활용

```json
{
  "function_declarations": [
    {
      "name": "get_district_info",
      "description": "서울 특정 구의 생활 정보를 조회",
      "parameters": {
        "type": "object",
        "properties": {
          "district": { "type": "string", "description": "서울시 구 이름" },
          "category": {
            "type": "string",
            "enum": ["waste", "office", "hospital", "transport"]
          }
        }
      }
    },
    {
      "name": "get_visa_info",
      "description": "체류자격별 행정 절차 안내",
      "parameters": {
        "type": "object",
        "properties": {
          "visa_type": { "type": "string" },
          "procedure": { "type": "string" }
        }
      }
    }
  ]
}
```

#### 4.3.3 Gemini Live API 활용 (음성 대화)

```
Browser Mic (PCM 16kHz) → WebSocket → FastAPI → Gemini Live API
                                                       ↓
Browser Speaker (PCM 24kHz) ← WebSocket ← FastAPI ← Audio Response
```

- WebSocket 엔드포인트: `WS /api/voice?language=English`
- 모델: `gemini-2.5-flash-native-audio-preview-12-2025` (폴백: `gemini-2.0-flash-live-001`)
- 프론트엔드: Web Audio API (ScriptProcessorNode) 기반, 추가 npm 패키지 없음
- 음성 전용 시스템 프롬프트: 짧고 대화체적인 응답 지향

#### 4.3.4 Grounding with Google Search 활용

실시간 정보가 필요한 질문에 대해 Google Search Grounding을 활성화하여 최신 정보를 기반으로 응답:

- 비자 정책 변경 사항
- 공공기관 운영 시간
- 교통 요금 변동
- 최신 외국인 지원 프로그램

## 5. 사용자 경험 (UX) 설계

### 5.1 핵심 사용자 플로우

```
[앱 진입]
    │
    ├── 언어 선택 (영어 / 중국어 / 베트남어 / 일본어 / etc.)
    │
    ├── 메인 화면
    │     │
    │     ├── 📸 "사진으로 질문하기" (카메라/갤러리)
    │     │     └── 이미지 업로드 → Gemini 분석 → 결과 카드 표시
    │     │
    │     ├── 💬 "직접 질문하기" (채팅)
    │     │     └── 텍스트 입력 → Gemini 응답 → 후속 질문 가능
    │     │
    │     └── 🗂️ "가이드 보기" (카테고리)
    │           └── 카테고리 선택 → 상세 가이드 표시
    │
    └── 설정: 언어 변경, 거주 지역 설정
```

### 5.2 UI 핵심 원칙

- **모바일 퍼스트**: 외국인 대부분이 스마트폰으로 접근
- **카메라 버튼 최우선**: 메인 화면 중앙에 큰 카메라 버튼 배치
- **결과의 구조화**: 분석 결과를 접이식 카드(Accordion)로 구분 (요약 / 상세 / 행동가이드)
- **다국어 우선**: UI 자체도 선택한 언어로 전환
- **복사/공유 기능**: 결과를 클립보드 복사 또는 메신저 공유 가능

### 5.3 화면 구성 (Wireframe 기준)

**메인 화면**: 상단 로고 + 언어 선택, 중앙 카메라 촬영 버튼(대형), 하단 채팅 입력바 + 카테고리 가이드 탭

**분석 결과 화면**: 업로드 이미지 썸네일, 문서 유형 배지, 핵심 요약 카드, 펼쳐서 상세 보기, "추가 질문하기" 버튼

**채팅 화면**: 일반적인 채팅 UI, 이미지 첨부 가능, 이전 대화 맥락 유지 (세션 내)

## 6. MVP 범위 및 우선순위

### 6.1 MVP (6시간 내 완성 — AI 도구 적극 활용)

| 우선순위 | 기능                                             |
| :------: | ------------------------------------------------ |
|    P0    | 이미지 업로드 + Gemini Vision 분석 + 결과 표시   |
|    P0    | 채팅 기반 Q&A (Gemini + Google Search Grounding) |
|    P0    | 다국어 응답 (최소 영어 + 1개 언어)               |
